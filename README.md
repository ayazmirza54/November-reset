# November Reset

Native offline Android habit tracker for November 2026. Tracks 13 daily habits, 30-day calendar, monthly score, streaks, expenses, and reflections.

## Build APK
GitHub Actions builds `app-debug.apk` on pushes to `main` or via **Actions → Build Android APK → Run workflow**. Download the `November30-debug-apk` artifact.

Java 17, Android SDK 35, Gradle 8.9.
